# Grill — menubar-and-installable-app

터미널에서 돌던 QuicMic 을 메뉴바 앱으로 만들고, 폰 쪽은 설치 가능한 웹앱으로 만들어 번호를 다시 묻지 않게 한다.

## 설계 트리

```
QuicMic 을 일상적으로 쓸 만하게
├── 맥에서 어떻게 띄우나
│   ├── 메뉴바가 터미널을 대체하나        → D1 (캡틴)
│   ├── 메뉴바에서 무엇을 보여주나        → D1 (캡틴, QR)
│   └── 번호는 어디서 바꾸나              → D3 (캡틴)
├── 폰에서 어떻게 여나
│   ├── 웹앱으로 설치 가능한가            → F4·F20 (사실)
│   ├── 아이콘은 무엇으로                 → D4 (캡틴)
│   └── 설치가 끝내 안 되면               → D5 (캡틴, 조건부)
├── 왜 매번 번호를 묻나
│   ├── 서버가 잊는가                     → F12 (사실)
│   └── QR 로 여는 것 자체가 지우는가     → F21 (사실)
└── 밖에서도 쓰나                          → D2 (캡틴, 집 안 전용)
```

## 라운드 로그

### 0라운드 — 사실 조사 (사관장, 2026-08-25)

캡틴께 여쭙기 전에 저장소를 읽어 F1~F27 을 확정했다.
그 결과 처음 \"설계 공백\" 으로 보였던 것 대부분이 **찾으면 나오는 사실**이었고, 캡틴께는 판단이 필요한 것만 올렸다.

특히 두 가지는 캡틴의 전제를 뒤집는 사실이었다:
- 설치 버튼이 안 뜬 이유는 인증서가 아니라 **manifest 가 아예 없어서**였다(F20). 즉 웹앱 경로는 시도된 적이 없다.
- 번호를 매번 묻는 이유가 서버 망각(F12) 하나가 아니라 **QR 로 여는 것 자체가 저장된 기록을 지우는**(F21) 두 겹이었다.

### 1라운드 (2026-08-25)

| # | 물은 것 | 캡틴이 정하신 것 |
|---|---|---|
| Q1 | 메뉴바가 터미널을 대체하나 | D1 — 대체한다 |
| Q2 | 아이콘은 무엇으로 | D4 — Tabler 마이크(사관장 추천을 뒤집음) |
| Q3 | 번호는 어디서 바꾸나 | D3 — 메뉴바에서 |

프론티어가 비었다.
남은 것은 사관장이 코드를 보며 정할 구현 질문뿐이고, 그중 하나(F22 의 service worker 가 자체 서명 인증서에서 등록되는가)는 **실물로만 답할 수 있어** spec 이 그것을 첫 티켓의 검증 항목으로 못박는다.

## 캡틴 결정 (원문)

### D1 — 메뉴바가 정상 경로다 (2026-08-25)

> \"집안 전용으로 하자. 메뉴바에 등록하고 클릭하면 qr 코드가 나오게 하자. 그걸 스캔해서 사용하도록 하자.\"

실행하면 메뉴바에 아이콘이 뜬다.
누르면 QR 이 보이고, 폰으로 찍어 짝짓는다.
터미널은 개발용으로만 남는다 — 캡틴이 일상적으로 터미널을 여는 일이 없어야 한다.

### D2 — 집 안 전용 (2026-08-25, 같은 지시)

cloudflared·`mic.pruge.uk`·공개 주소·접근 제어는 **전부 범위 밖**이다.

근거: Cloudflare 터널은 origin 으로 WebTransport/HTTP-3 를 나르지 못한다(HTTP/1.1·HTTP/2·WebSocket·TCP-over-WebSocket 뿐이고, HTTP/3-to-origin 은 공식 미지원).
터널을 쓰면 느린 WebSocket 폴백으로만 돌게 되어 이 도구를 쓰는 이유를 깎는다.
부수 효과로 **인터넷에서 캡틴의 Mac 에 소리를 밀어 넣을 입구가 애초에 생기지 않는다** — 막는 것이 아니라 만들지 않는 쪽이다.

### D3 — 번호는 메뉴바에서 바꾼다 (2026-08-25)

> \"quicmic는 webapp으로 설치가능하게 하자. pin은 한번 설정하면 내가 갱신하지 않는한 그대로 유지하게하자. webapp을 다시 실행시키면 자동으로 연결하자. 다시 pin을 묻지 말자.\"

번호는 캡틴이 바꾸기 전까지 그대로다.
바꾸는 자리는 메뉴바다(1라운드 Q3).

### D4 — 아이콘은 Tabler 마이크 (2026-08-25)

> \"icon은 tabler icon에서 microphone을 사용하도록하자.\"

🔴 사관장은 기존 손그림을 크게 다시 그리자고 추천했으나 캡틴이 뒤집었다.
기록으로 남긴다 — 이 결정은 취향이지 기술적 제약이 아니었다.

### D5 — 안 되면 안드로이드 앱 (2026-08-25, 조건부)

> \"web app이 안되면 anroid tauri app으로 만들자.\"

**아직 발동하지 않았다.** F20 이 밝혔듯 웹앱은 시도된 적이 없고 실패한 적도 없다.
발동 조건: manifest·아이콘·인증서 지속까지 갖춘 뒤에도 캡틴의 실제 안드로이드 기기에서 설치가 거부될 때.
그때는 짐작이 아니라 실패 증거를 들고 간다.

## 사관장이 확정한 사실

### 메뉴바 (D1)

- **F1** QuicMic 은 화면 요소가 하나도 없는 Rust CLI 다. `src/{main.rs,tls.rs,update_check.rs,audio/,server/}` 이고 Cargo.toml 에 UI·tray 의존이 없다. **앱 껍데기(.app·Info.plist·entitlements) 자체가 없다** — 메뉴바는 새로 짓는 표면이다.
- **F2** 켜두고 계속 도는 전경 프로세스라 메뉴바가 제자리다.
- **F3** QR 은 이미 있다: `qr2term = \"0.3\"`(Cargo.toml:91)로 `qr2term::print_qr(&qr_url)`(main.rs:213). 🔴 **터미널 전용 크레이트다** — 메뉴바 팝오버는 이미지가 필요하므로 이 경로를 그대로 못 쓴다.
- **F28** 짝짓기에 필요한 값은 `print_banner`(main.rs:342)가 이미 한자리에 모은다: URL·번호·인증서 지문. 메뉴바는 같은 값을 다른 모양으로 보여줄 뿐이다.
- **F29** 종료 경로가 이미 있다: `ctrl_c` → `is_shutdown` → `axum_handle.graceful_shutdown`(main.rs:285~303). 메뉴바 Quit 은 이 경로를 부르면 되고 새 정리 로직이 필요 없다.

### 설치 가능한 웹앱 (D3)

- **F4** manifest·service worker 가 **저장소 어디에도 없다**(`manifest*.json`·`*.webmanifest`·`sw.js`·`service-worker*` 전부 0건).
- **F20** 🔴 **설치 버튼이 안 뜬 진짜 이유다.** `grep -c 'rel=\"manifest\"' web/index.html` = 0, `grep -c serviceWorker web/app.js` = 0. 브라우저는 설치할 수 있다고 선언하지 않은 페이지에 설치를 권하지 않는다. 인증서 문제(F17)는 **그다음에** 부딪힐 문제였다.
- **F5** 절반은 준비돼 있다: `web/index.html` 이 `apple-mobile-web-app-capable`·`apple-mobile-web-app-status-bar-style`·`theme-color` 를 이미 갖고 있다.
- **F6** 웹 자산은 `rust_embed` 로 바이너리에 박힌다(`src/server/assets.rs`). `web/` 에 파일을 더하면 자동으로 실린다 — 별도 배포가 없다.
- **F26** 기존 인라인 favicon 은 **64×64**(base64 디코드해 실측). 설치에는 192×192·512×512 가 필요하다. **원본이 무엇이든 크기는 새로 뽑아야 한다.**
- **F27** 같은 그림이 **메뉴바와 웹앱 양쪽**에 쓰인다. 한 출처에서 파생해야 어긋나지 않는다.

### 아이콘 (D4)

- **F23** Tabler Icons 는 MIT 다. 화면에 출처를 표시할 의무는 없다. 다만 **그림 파일을 함께 배포하므로 라이선스 문구는 동봉해야 한다**(F6 때문에 파일이 바이너리에 들어간다).
- **F24** 무료 묶음에 마이크 아이콘이 있다(`microphone`·`microphone-2`·`microphone-off`), SVG 로 받는다.
- **F25** 지금 아이콘 라이브러리를 하나도 안 쓴다 — Cargo.toml·style.css 어디에도 없고 `web/` 은 딱 네 파일이다. Tabler 아이콘은 **패키지 의존이 아니라 vendored 자산 파일**로 들어온다.

### 번호 고정 (D3)

- **F8** 지금은 **실행할 때마다 새로 뽑는다**: `format!(\"{:06}\", rand::random_range(0..1_000_000u32))`(main.rs:204), `--pin` 이 없을 때만.
- **F9** 🔴 **디스크에 아무것도 저장하지 않는다.** `src/` 어디에도 config-dir·data-dir·설정 파일 쓰기가 없다. 번호를 고정하려면 **기억하는 자리를 새로 만들어야 한다.**
- **F10** `--pin` 은 이미 있다. 할 일은 캡틴이 매번 값을 넣지 않아도 유지되게 하는 것이다.

### 다시 묻지 않기 (D3)

- **F11** 폰 쪽은 이미 만들어져 있다: `localStorage` 에 토큰을 저장하고(app.js:626,656), 열 때 `storedToken` → `renewSessionToken()`(app.js:286~292,342)을 시도한다.
- **F12** 🔴 **서버 쪽이 없다.** 세션 토큰이 메모리에만 산다(`Arc<parking_lot::Mutex<Option<String>>>`, server/state.rs:19). 재시작하면 사라지고 `/api/renew` 가 어긋나 `returnToPairing(...)` 으로 떨어진다 — 그것이 \"번호를 다시 묻는\" 화면이다.
- **F21** 🔴 **두 번째 원인.** QR 은 번호를 URL 해시로 싣고(`format!(\"{}#{}\", url, pin)`, main.rs:212), `app.js:275~283` 의 해시 분기가 **`localStorage.removeItem('sessionToken')` 을 먼저 실행한다.** 즉 **QR 로 여는 한 서버를 고쳐도 여전히 묻는다.** 해시 없이 열어야 재사용 분기(app.js:285~293)를 탄다.
- **F22** 🔴 **두 요청이 한 덩어리인 이유.** 웹앱으로 설치하면 아이콘으로 여는 것이 곧 **해시 없는 실행**이고, 그때 비로소 이미 만들어진 재연결이 작동하며, 그 재연결이 성공하려면 서버가 토큰(F12)과 인증서(F17)를 기억해야 한다.

### 인증서 (F22 의 마지막 고리)

- **F17** 🔴 TLS 신원이 **매 실행 메모리에서 새로 만들어지고 저장되지 않는다**(`tls.rs` `generate_identity`, `Identity::self_signed([\"localhost\", <lan_ip>])`; `--dump-certs` 는 디버그용 사본일 뿐). `web/app.js:384` 주석이 그 사실을 명시한다.
- **F16** 신뢰 설치 경로는 **이미 있다**: `GET /ca` 가 DER 로 `quicmic-ca.cer` 를 내려준다(server/mod.rs:71, api.rs:390).
- **F15** 안드로이드 Chrome 은 자체 서명이라고 무조건 막지 않는다 — **신뢰 저장소에 넣으면 secure context 로 인정한다.** 경고를 클릭해 넘기는 것은 세션 한정이라 service worker 등록에 신뢰할 수 없다.
- **F30** 🔴 인증서를 저장하면 **클라이언트 인증서 고정에도 영향이 있다.** `app.js:1210~1215` 가 `/api/info` 의 `cert_hash`(api.rs:100)를 받아 `serverCertificateHashes` 로 WebTransport 를 연다. 인증서가 안 바뀌면 이 해시도 안 바뀌므로 **오히려 안정된다** — 지금은 재시작마다 해시가 달라져 `app.js:390` 의 \"Server closed / 새로고침\" 경로가 필요했다.
- **F31** 저장해야 할 것의 모양은 이미 정의돼 있다: `TlsIdentity { cert_pem, key_pem, cert_der, cert_hash_base64 }`(tls.rs:12~20). PEM 두 개를 보관하면 나머지는 파생된다.

### 하나의 저장소가 셋을 푼다

- **F18** 인증서(F17)·번호(F9)·세션 토큰(F12)이 **모두 같은 이유**로 막혀 있다: 이 프로그램은 아무것도 기억하지 않는다.
  기억하는 자리 하나를 만들면 셋이 함께 풀리고, 덤으로 `app.js:390` 의 강제 새로고침 경로가 존재 이유를 잃는다.

## 보안 — 캡틴이 알고 택한 거래

번호가 안 바뀌고 세션이 재시작을 넘어 살아남는 것은 지금 자세를 **약화시킨다**(지금은 재시작마다 번호가 새로 뽑히고 모든 세션이 끊긴다).
집 안 전용(D2)이고 연속 실패 시 30초 잠금(server/state.rs:34~37)이 있어 합리적인 거래지만, **저장 파일은 캡틴만 읽을 수 있어야 한다.**

## 용어

새 용어를 만들지 않는다.
`짝짓기 번호`(pairing PIN)·`세션 토큰`·`가상 장치`는 이미 이 저장소가 쓰는 말이다.
`기억하는 자리`는 spec 에서 정확한 이름을 정한다.
