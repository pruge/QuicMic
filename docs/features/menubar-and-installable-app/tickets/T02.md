# T02 — 메뉴바 앱으로 띄운다

## Goal

QuicMic 을 실행하면 **메뉴바에 마이크 아이콘**이 뜨고, 누르면 QR·주소·번호·연결 여부가 보이며, 거기서 번호를 새로 만들거나 종료할 수 있다.
터미널은 개발용으로만 남는다.

## Why this slice

캡틴이 일상적으로 QuicMic 을 쓰는 **정상 경로**다(D1).
지금은 터미널을 열고 명령을 쳐야 하며, QR 도 터미널 안에만 있다.

## Produces

맥용 메뉴바 표면과, 그 안에서 보이는 짝짓기 정보(QR·주소·번호·연결 여부)와 두 동작(번호 새로 만들기·종료).
그리고 **Tabler 마이크 아이콘의 vendored 원본**(T03 이 이것을 재사용한다).

## Consumers

메뉴바가 보여주거나 불러야 할 기존 자리:

- `src/main.rs:342~372` `print_banner` — URL·번호·인증서 지문을 이미 한자리에 모은다. 🔴 **메뉴바는 같은 값을 다른 모양으로 보여줄 뿐이다.** 값 계산을 두 번 만들지 마라.
- `src/main.rs:208` — `let url = format!("https://{}:{}", url_host(&lan_ip), cli.port)`. 표시할 주소.
- `src/main.rs:212` — `let qr_url = format!("{}#{}", url, pin)`. 🔴 **QR 이 담는 것은 이 해시 붙은 주소다.** T03 의 자동 재연결과 직결되므로 형식을 바꾸지 마라.
- `src/main.rs:213` — `qr2term::print_qr(&qr_url)`. 🔴 **터미널 전용 크레이트다**(Cargo.toml:91). 메뉴바 팝오버는 이미지가 필요하므로 **이 경로를 그대로 못 쓴다** — QR 을 이미지로 만드는 길이 따로 필요하다.
- `src/main.rs:285~303` — `ctrl_c` → `is_shutdown.store(true)` → `axum_handle.graceful_shutdown(...)`. 🔴 **메뉴바 종료는 이 경로를 불러야 한다.** 새 정리 로직을 만들지 마라.
- `src/server/state.rs` `is_connected` — 연결 여부 표시의 출처.
- `src/main.rs:197`·`:256` — 번호. T01 이 저장소로 옮긴 뒤이므로 **새로 만들기는 저장소에도 반영돼야 한다.**

## Touched surfaces

- `src/main.rs` — 시작 경로가 메뉴바를 세우도록
- 메뉴바 표면의 새 모듈
- `Cargo.toml` — 트레이 의존과 QR 이미지 생성 의존
- `web/` 또는 새 자산 폴더 — Tabler 마이크 SVG 원본과 라이선스 문구
- 맥 앱 껍데기(있어야 한다면) 관련 파일
- 위의 테스트

## Explicitly out of scope

- 웹앱 manifest·service worker·웹 아이콘 크기 — **T03 이 소유한다.** 이 티켓은 Tabler 원본을 vendoring 하고 메뉴바용 크기만 만든다.
- 저장소 자체 — T01 이 만든 것을 쓴다.
- 전송·오디오·짝짓기 규약 변경.
- 윈도우·리눅스 트레이 — 거저 따라오지 않는 한 만들지 마라.
- 코드 서명·공증.

## Locked decisions

- **D1**(`grill.md`): 메뉴바가 **정상 경로**다. 터미널 실행은 개발용으로 남긴다 — 지우지 마라(`spec.md` 수용기준 10).
- **D4**(`grill.md`): 아이콘은 **Tabler 마이크**다. 기존 손그림을 쓰지 마라.
- **F23**(`grill.md`): Tabler 는 MIT 다. 화면 표시 의무는 없으나 **파일을 함께 배포하므로 라이선스 문구를 동봉해야 한다**(F6 — `rust_embed` 가 자산을 바이너리에 박는다).
- **F29**(`grill.md`): 종료는 기존 경로를 재사용한다.
- **D3**(`grill.md`): 번호를 바꾸는 자리는 메뉴바다.

## Implementation notes

🔴 **앱 껍데기가 아예 없다**(F1) — `.app`·`Info.plist`·entitlements 가 저장소에 하나도 없고, 패키징 스크립트도 없다.
메뉴바 아이콘을 띄우려면 macOS 가 요구하는 최소 구조를 새로 만들어야 한다. 그 무게를 감안해서 접근을 골라라.

Rust 바이너리에 전체 앱 프레임워크를 끌어들이지 않는 쪽을 우선 검토해라.
의존이 크게 늘어난다고 판단되면 멈추고 `needs-decision:` 으로 선택지를 보고해라.

QR 이미지: `qr2term` 은 못 쓰지만 같은 문자열을 이미지로 만드는 크레이트로 바꾸면 된다. **QR 이 담는 문자열(`main.rs:212`)은 바꾸지 마라.**

## Evidence anchors

- `src/main.rs:208`·`:212`·`:213` — 주소·QR 문자열·QR 출력
- `src/main.rs:285~303` — 종료 경로
- `Cargo.toml:91` — `qr2term = "0.3"`

## Regression guards

- `cargo test` 전체
- 터미널 실행 경로가 여전히 동작하는지 수동 확인

새로 져야 할 것: 메뉴바에 보이는 값이 `print_banner` 와 일치하는지, 종료가 기존 경로를 부르는지, 번호 새로 만들기가 저장소에 반영되는지.

## Acceptance criteria

1. 실행하면 메뉴바에 마이크 아이콘이 뜬다.
2. 누르면 QR 이 보이고 폰으로 찍어 짝지어진다.
3. 주소·번호·연결 여부가 보인다.
4. 번호를 새로 만들 수 있고, 그 값이 저장소에 남아 재시작 후에도 유지된다.
5. 메뉴에서 종료하면 `Ctrl+C` 와 같은 정리가 일어난다.
6. 터미널 실행 경로가 여전히 동작한다.
7. Tabler 라이선스 문구가 배포물에 들어 있다.
8. `cargo test` 전체 통과.

## Verification

`cargo test` 로 시작한다.
수동: 실행 → 메뉴바 확인 → QR 로 짝짓기 → 번호 새로 만들기 → 재시작해 유지 확인 → 메뉴에서 종료.
전체 출력은 `/tmp` 아래에 남겨라.
