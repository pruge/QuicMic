# T04 — 네이티브 기본 화면: 홈/설정 두 탭 + QR 스캔 연결 (D7/V2)

## Goal

래퍼 앱이 WebView 로 곧장 웹 UI 를 띄우는 대신, **네이티브 홈/설정 두 탭** 기본 화면을 갖게 한다.
홈 탭 = 연결 상태·"QR로 연결" 버튼·오디오 미터. 설정 탭 = 서버 주소·QR 스캔·수동 PIN 입력·지문 관리.
연결되면 기존 WebView 가 화면을 담당한다(웹 UI 재사용 — D7 프로토타입 V2).

## Why this slice

캡틴 지시(2026-08-26): `pnpm install:quicmic` 으로 깔린 앱의 기본 화면이 있어야 하고,
설정에서 "QR 코드로 연결"을 누르면 Mac 메뉴바 QR 을 스캔해 연결하게 한다.
프로토타입(design/default-screen-prototype.html)에서 V2 로 확정됨(grill.md D7).

## Produces

- 홈/설정 하단 탭 네이티브 골격
- CameraX + ML Kit 기반 QR 스캐너 → `https://<host>:<port>#<pin>` 파싱 → 서버 저장·PIN 자동 페어링
- 홈 탭: 연결 상태 카드, QR 버튼, 스트리밍 중 오디오 레벨 미터(웹에서 수신한 값 또는 근사)
- 설정 탭: 서버 주소 표시·수동 수정, 수동 PIN 입력, 신뢰한 인증서 지문 보기·삭제(TofuStore 재사용)

## Consumers

- `TofuStore.kt` — 지문 저장·조회·삭제로 재사용 (PR #12 에서 착지)
- `ServerDiscovery.kt` — 서버 탐색 재사용
- 웹 UI(`code/web/app.js`) — 연결 후 컨텐츠는 여전히 웹이 담당; 앱은 URL 구성만 바뀜

## Acceptance criteria
