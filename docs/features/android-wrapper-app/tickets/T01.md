# T01 — code/ 모노레포로 개편 (웹 자산 이동 + pnpm workspace)

## Goal

저장소를 `code/` 모노레포 구조로 바꾼다: `web/` → `code/web` 이동, `pnpm-workspace.yaml` 도입,
기존 pnpm 명령 전부 유지. Rust 서버는 루트에 그대로.

## Why this slice

이후 모든 클라이언트 계열(android 등)이 `code/` 아래에 얹히는 자리를 먼저 만든다.
파일 이동 한 번으로 끝나는 기계적 변경이라 앱 작업과 섞지 않는다.

## Produces

새 저장소 레이아웃: `code/web/**`(기존 web/ 전부) + `pnpm-workspace.yaml` + 동작이 동일한 루트 package.json.

## Consumers

- `src/server/assets.rs:13` — `#[folder = "web/"]` → 새 경로로 수정해야 하는 유일한 코드 참조
- `src/server/assets.rs:251` — panic 메시지 안의 `web/` 문자열(테스트)
- README 의 web/ 경로 언급 — 있으면 수정
- `.github/workflows/` — 경로 참조 없음(grep 확인, 2026-08-26)

## Touched surfaces

- `web/**` → `code/web/**` (git mv)
- `src/server/assets.rs` (folder 속성 1줄 + 메시지 1줄)
- `pnpm-workspace.yaml` (신규)
- `package.json` (스크립트 경로 확인·필요 시 수정, 별칭 유지)
- `README.md` (경로 언급)

## Explicitly out of scope

- Rust 소스 이동 — 루트 유지(D1)
- 안드로이드 관련 그 어떤 것도 없음(T02)
- CI 파일 변경

## Locked decisions

- D1(`grill.md`): code/ 모노레포, Rust 루트 유지
- 캡틴 지시(2026-08-26): 컴파일 시 다른 것을 다운받게 하지 않는다 — workspace 도입도 기존 의존성 잠금 유지

## Evidence anchors

- `src/server/assets.rs:12~14` — embed 폴더 선언
- `package.json` scripts — 별칭 전부
- `cargo test` 전체

## Regression guards

- `cargo test` 전체 통과
- `pnpm dev/build/test/app:install:*` 별칭 전부 실측 동작
- 서버 실행 시 웹 UI 정상 서빙(`/manifest.json`, `/sw.js` 200)

## Scope

1. git mv 로 웹 자산 이동
2. embed 경로·메시지 수정
3. workspace 파일 추가, 스크립트 점검
4. 빌드·테스트·명령 실측

## Implementation notes

- git mv 로 히스토리 보존.
- rust_embed 는 컴파일 타임 폴더 참조라 경로 변경 후 clean build 로 확인.
- pnpm workspace 는 code/web 에 package.json 을 요구하지 않게 설정(자산 폴더일 뿐이다).

## Acceptance criteria

1. `code/web/` 에 웹 자산이 있고 `web/` 은 없다
2. `cargo build --release` + `cargo test` 통과
3. 서버 실행 → 웹 UI 정상 표시, manifest/sw.js 200
4. 기존 pnpm 명령 전부 동작
5. 커밋에 AI co-author 흔적 없음

## Verification

cargo test + 각 pnpm 명령 실측, 출력은 /tmp 아래 기록.
