# T02 — 안드로이드 래퍼 앱 (WebView + TOFU 신뢰 + 설치 스크립트)

## Goal

`code/android` 에 Kotlin WebView 래퍼 앱을 만든다: LAN 서버 웹 UI 를 전체화면으로 띄우고,
첫 연결 때 인증서 지문을 수락받아 고정하며(TOFU), 집 밖에서는 안내 화면을 보여준다.
`pnpm build:android` / `pnpm install:quicmic` 으로 빌드·USB 설치된다.

## Why this slice

D5 의 실체다. 자체 서명 CA 로는 WebAPK 독립 설치가 불가(실물 확정)해서, 네이티브 껍데기가
신뢰를 대신 담당한다. UI 는 서버 실시간 제공이라 이 앱은 거의 변하지 않는다.

## Produces

- 디버그 APK 하나 (applicationId `com.pruge.quicmic`, minSdk 29)
- TOFU 지문 수락·저장·불일치 차단 흐름
- LAN 도달 불가 안내 화면
- Tabler 마이크 아이콘 파생 앱 아이콘(code/web 의 vendored 원본 재사용)
- 루트 pnpm 스크립트: `build:android`(gradlew assembleDebug), `install:quicmic`(빌드+adb 설치+실행)

## Consumers

- `code/web/vendor/tabler/` — 아이콘 원본(T02 가 소비해 파생). 웹 자산 자체는 무변경
- jinwooauto `scripts/android-install.sh` — 참조 구현(차용 지점): gradlew 검증→빌드→adb devices 열거→install -r -d
- 이 맥의 Gradle 캐시 — jinwooauto 와 동일 버전(Gradle 8.11.1/AGP 8.7.3/Kotlin 2.1.0)이라 재활용

## Touched surfaces

- `code/android/**` (신규 Gradle 프로젝트: settings.gradle.kts, build.gradle.kts, gradle/libs.versions.toml, app 모듈, git 추적 wrapper)
- `package.json` (build/install 스크립트 2줄 추가)
- `scripts/android-install.sh` (신규 — jinwooauto 패턴 단순화판: 앱 1개, --prod 불필요)
- `README.md` (설치 방법 한 절)

2. MainActivity: URL 구성(`https://<탐지된 서버>:8443`)→로딩, SSL 오류 시 지문 TOFU 대화, 저장된 지문과 대조
3. 연결 실패 시 안내 화면(재시도 버튼)
4. 앱 아이콘(vendored 마이크 SVG→PNG 밀도 세트)
5. scripts/android-install.sh + package.json 스크립트
6. README 설치 절

## Implementation notes

- 🔴 무료 모델 크루는 글자만 다룬다 — 스크린샷·이미지 확인 금지. 실물 확인은 말단 검수 티켓(T03)이다.
- 지문 계산: 인증서 DER 의 SHA-256. 저장 키는 호스트:포트.
- WebView localStorage 가 토큰을 저장하므로 재연결은 웹 로직이 알아서 한다 — 앱이 건드리지 않는다.
- cleartext 금지(HTTPS 만), INTERNET 권한만 선언.
- gradlew 없으면 Android Studio sync 안내로 실패하는 jinwooauto 패턴 유지.

## Acceptance criteria

1. `pnpm build:android` 성공 — 빌드 중 새 다운로드는 캐시 없는 필수 산출물로 최소화
2. `pnpm install:quicmic` → USB 폰에 설치되고 앱이 실행된다
3. 첫 실행: 지문 대화 → 수락 → 웹 UI 전체화면; 두 번째 실행: 질문 없음
4. 인증서 재생성(LAN IP 변경 등) 시: 차단 → 재확인 후 복구
5. 비행기 모드/외부 네트워크: 안내 화면 + 재시도
6. 앱 안에서 QR 짝짓기 → 스트리밍 시작까지 웹과 동일 동작(검수 티켓에서 실물 확인)
7. `cargo test` 여전히 통과(서버 무변경 확인)
