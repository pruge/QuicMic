# T03 — T-review: 사관장 검수 (안드로이드 래퍼 앱)

## Goal

캡틴이 실물 폰에서 설치→신뢰→짝짓기→재연결→스트리밍을 직접 확인한다.

## Why this slice

TOFU 신뢰 UX 와 WebView 안의 웹 동작은 기계로 증명할 수 없다. 무료 모델 크루는
화면을 볼 수 없으므로(함대 규칙) 말단 검수는 캡틴 몫이다.

## Produces

수용 판정. 지적이 나오면 별도 후속 작업.

## Consumers

- `docs/features/android-wrapper-app/spec.md` §Acceptance criteria — 단일 출처
- `docs/features/android-wrapper-app/grill.md` D1~D6

## Touched surfaces

없음 — 코드를 만들지 않는다.

## Explicitly out of scope

- 실시간 대화형 검수 루프(개발 완료 후 검수 — 캡틴 방침)
- 검수 중 발견된 새 기능 구현

## Locked decisions

- 개발 완료 후 검수, 작업자 대기 없음(캡틴 지시 2026-08-25)

## Evidence anchors

- spec.md §Acceptance criteria 1~7

## Regression guards

T01·T02 테스트 전부 통과 상태에서 검수에 들어간다.

## Acceptance criteria

캡틴이 실물 폰에서 확인한다:

1. `pnpm install:quicmic` 으로 설치되고 아이콘이 뜬다
2. 첫 실행 → 인증서 지문 수락 → 전체화면 웹 UI
3. 두 번째 실행부터 질문 없이 바로 연결
4. QR 짝짓기 후 소리가 VB-Cable 로 흐른다
5. 앱 종료→재실행: 번호 없이 자동 재연결
6. 외부 네트워크에서는 안내 화면

## Verification

캡틴 직접 확인.
